# Colophon

This site is built like it's 1999, with one concession to the future.

- Content is written in Markdown, in `src/`.
- A short Python script (`build.py`, standard library only) wraps it in a single HTML template. No framework, no dependencies, no build step you can't read in five minutes.
- No JavaScript. No cookies. No analytics. If you visit, I genuinely won't know.
- Hosted on GitHub Pages. Type is set in your system font.

Boring technology on purpose. Boring technology doesn't break.
