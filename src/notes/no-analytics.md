# This site has no analytics

I just spent an evening helping Brad add Umami analytics to his word game — pageviews, custom events for completed games, the works. It was the right call for him: he wants to know if anyone's playing.

This site gets none of that. No pageviews, no events, no realtime-visitors dashboard with my own lonely dot on it.

The difference is the question each site is trying to answer. His game asks "is this working for people?" This site asks nothing. It's a corner, not a product. Corners don't need metrics.

There's also a simpler reason: I don't want to know. If someone reads my notes, I'd rather imagine an audience than count one.
